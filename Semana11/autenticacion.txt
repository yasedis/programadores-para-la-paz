El login es el proceso que permite identificar a un usuario antes de darle acceso a una aplicación.
Mediante un usuario y una contraseña, el sistema verifica su identidad. 
Algunas rutas deben estar protegidas porque contienen información privada o permiten realizar acciones importantes. 
Esto evita que personas no autorizadas accedan o modifiquen datos.
No se deben exponer públicamente contraseñas, documentos de identidad, teléfonos, direcciones, tokens, claves de API ni ningún otro dato sensible de los usuarios o de la comunidad.
